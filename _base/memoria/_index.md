# Memória compartilhada entre projetos

Aprendizados generalizáveis que não pertencem a um projeto específico.

## Estrutura

- `learnings/` — generalizações úteis cross-projeto
- `referencias/` — material de referência (políticas, templates aprovados)

## Não escrever aqui

- Conhecimento específico de cliente → vai em `projetos/<slug>/memoria/`
- Estado runtime → não persistir aqui
